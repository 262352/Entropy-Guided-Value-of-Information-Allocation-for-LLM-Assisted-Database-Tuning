# 方法稿内部维护说明（2026-11-05：符号、接口与公式层次修订）

本文档供代码对齐和实验维护使用，不属于投稿正文或补充材料。
用户要求论文直接描述完整方法：除框架图外不放占位、作者备注、实现状态或提交前待办。
本轮据此清理了正文与补充材料；没有修改优化器代码、调用付费API或启动真实调优。

## 当前论文主线

执行反馈塑造“调哪些旋钮、在哪些区域、分配多少候选容量”。一个动作对应完整状态
(A,R,b)：先为该动作的分布建立等规模审计，计算机会信用和配额，再用配额加权的
审计机会给动作评分。b 因而参与动作比较，不再仅仅在选定 A/R 后被动更新。

动作分数是按候选份额抽到某一模式时，其最佳审计点的后验正增益期望。
它是搜索机会决策准则，不应解释为已证明的全局最优或最终TPS保证。
比较不同状态时复用不变分布的审计点和联合后验样本，控制查询与生成成本。

## 本轮补全项

- GP统一为 `P_t`，专家提议为 `mathcal P`；拟合、审计、信息估计和证据更新均使用同一GP符号。
- 所有候选生成函数接收已尝试集合V，包含失败配置；最终合并再去重过滤。现有优化器的seen
  本来包含所有记录，此处补全论文中的显式约束，未改动运行代码。
- 将专家提议编译为Q（分布、补丁种子、已审核跨域补丁和锚点/作用域）；Fill只按Q程序采样。
  Reserve明确IID参考、跨域、覆盖及重入通道，记录使用的驻留/覆盖/等待/失败信息。
- Info返回逐候选的估计/标准误对，算法使用带候选索引的返回值。
- 最终窗口改为B=T-n0，w_end=min(B,max(1,ceil(0.1B)))，默认50/10为4次，不再固定6次。
  此窗口调整属于方法方案，现有stable中的固定6次尚未更改，后续实现须更新协议。
- 原挤在一组的联合决策公式拆成“状态机会”“相对优势”“准入与选择”三组，分别解释；
  保留组内直接相关量。正文现有10个显示公式，而不是把每个量单独编号。

- 明确模式数 `1 <= |H| <= min(12, floor(Ng/bmin))`，显式定义
  `Nrem = Ng - |H| bmin >= 0`。重复组先合并，超限按领域覆盖与条件增益确定性保留。
- Calibrated(M) 用执行前预测的标准化残差，方差包含潜在函数方差与观测噪声。
  至少8次成功自适应预测，最近至多20次落入1.96标准差内的比例不低于0.7。
  初始IID样本不作为训练内校准残差。门未通过时保留A/R，继续EI与预留执行探针。
- 信息量用16个独立外层含噪幻想；每个熵用256个内层潜在样本估计。
  sigma_MC = sqrt(sum((R_f - mean(R))^2) / (F(F-1)))。
  该标准误是外层幻想采样误差，不是内层熵偏差或预测校准的替代。
- 至多4个动作是固定槽位：保持、目标组重塑、交换、交换加关联组重塑。
  有交换资格时选择最低条件增益的可退休组，否则选择最低增益活动组做区域复核。
  每槽位用等量初步探针评分，按少变动、旋钮ID及数值中心/半宽打破并列。
  交换仍必须胜过旧组的最佳合法重塑。
- 日志规范区分生成、专家批准、分位样本充分、校准通过、比较通过、实际采纳。
  扩展/收缩/平移/保持均按区域记录，另报全部自适应轮和可用决策中的比例。
  尚无新版真实频率，本轮没有编造百分比或消融收益。
- 补充材料有符号表、核心参数全表、附加固定设置表，覆盖T、n0、N、Ng、Nr、m、
  bmin、da、delta、eta、lambda、alpha、rho，以及采样、驻留、覆盖、模型和调用设置。
- 统一 knob=单旋钮、group=一起改变的旋钮组、mode=组及其分布和来源、action=备选搜索状态；
  utility=归一化对数指标，gain=utility之差。专家为LLM角色，controller执行确定性规则。

## 文章与实现边界（仅在这里记录）

以下机制仍需接入当前 stable：自适应最终窗口与显式接口组织；共同评分熵初始化；四槽位联合状态比较；后验半宽数据包与
动作审批；对所有备选状态先审计/分配并纳入动作评分；必填专家失败时的持续合法回退。
当前 stable 的 focus 排序、独立旋钮/范围规则、先按旧信用分配再审计，均与新稿不同。
不能把原50轮或旧的消融结果重新标成本文完整方法；需新协议身份和独立检查点。
已有测试通过只证明现有仓库回归未破坏，不验证尚未实现的新算法。

正式实现时还须记录按组件计时和额外提示token。128点参考集上限和复用已有调用不意味着
实际时间/最终TPS必然不降低。不能以不增加执行次数替代耗时验证。

## 消融定义

建议保留三种可区分的实验定义：

1. 联合：所有备选状态先审计/分配，用完整状态得分选择。
2. 顺序：先按旋钮条件机会换组，再独立修范围，最后分配候选。
3. 分离：旋钮和范围各用自己的局部准则，互不比较“修旧范围”和“换新组”的机会。

各版本保持共享初始设计、真实预算、候选上限、模型/提示策略和可行性规则；并单独控制
配额是否进入结构评分。另比较纯qLogNEI与信息选择、共同评分中是否加熵，以及区域
后验数据包。现有五种消融CLI并没有自动实现这些组合。本轮只完成方法稿及定义。
